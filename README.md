# OldMC

OldMC 是一个客户端 Fabric 模组。创建或打开世界时，区块图上方会像 Minecraft 1.21.8 一样显示加载百分比。数字使用游戏报告的实际进度，并跟随游戏语言。加入服务器或切换维度时，若客户端只有接收地形提示，则沿用 1.21.8 的显示方式。

按 F3 打开调试界面时，左栏从版本、帧率和服务器信息开始，坐标与世界信息排在下方。右栏显示 Java、内存、硬件和准星指向的目标。默认预设会启用旧版对应的条目；已保存的自定义选择仍然生效。在 F3+F6 中，每个条目仍支持关闭、仅打开调试界面时显示或始终显示。

## 设置

在「选项 → 视频设置 → OldMC 设置」中调整功能。安装与游戏版本匹配的 Sodium 0.8.0 或更高版本后，视频设置左侧的 OldMC 分类会显示「OldMC 设置」，退出后返回 Sodium 视频设置。安装 Mod Menu 后也能从 OldMC 的配置按钮打开同一界面。选项默认开启，离开配置界面时写入 `config/oldmc.json`。

- 世界加载百分比、完成后显示“加载地形中…”、1.21.8 默认大小的区块图（29×29 格）各有独立开关。开启三项时，进度到达 100% 后，区块图消失，随后显示地形提示。
- 「泥土背景」恢复 1.20.4 的菜单和世界加载背景。「准备创建世界」「保存世界中」等提示以白字显示在距顶部 70 个 GUI 像素处。
- 切换旧版 F3 布局后，当前条目按所选布局排列。F3+F6 的「默认配置」随开关选择条目清单，点击后应用，无需重启。
- 26.1–26.3 额外提供旧版游戏版本号开关，可选择「年份更新格式」（默认）或「大版本更新格式」。主菜单、窗口标题、F3 与相关版本提示使用下表的显示名称。联网使用实际游戏版本及协议号。

| 实际版本 | 年份更新格式 | 大版本更新格式 |
| --- | --- | --- |
| 26.1 | 1.26 | 1.22 |
| 26.1.1 | 1.26.1 | 1.22.1 |
| 26.1.2 | 1.26.2 | 1.22.2 |
| 26.2 | 1.26.3 | 1.23 |
| 26.3 | 1.26.4 | 1.24 |

## 构建

使用 JDK 25，在包含 `gradlew` 的项目根目录运行：

```sh
./gradlew build
```

Windows 使用 `gradlew.bat build`。两个安装包都会输出到根目录的 `build/libs/`，按游戏版本选一个放进客户端的 `mods/` 文件夹。

| Minecraft 正式版 | 安装包 | 游戏运行时 |
| --- | --- | --- |
| 1.21.9、1.21.10、1.21.11 | `oldmc-0.0.8-hotfix+mc1.21.9-1.21.11.jar` | Java 21 或以上 |
| 26.1、26.1.1、26.1.2、26.2、26.3 | `oldmc-0.0.8-hotfix+mc26.1-26.3.jar` | Java 25 或以上 |

两个安装包均使用 Fabric Loader 0.20.1 或以上版本，无需 Fabric API。只构建一个目标时，使用 `./gradlew :mc1_21:build` 或 `./gradlew :mc26:build`。

## 源码

包名为 `me.mudkipx.oldmc`。显示逻辑位于 `src/client/java/`，两个版本系列各自的渲染方法签名位于 `mc1_21/` 和 `mc26/`。工程基于 FabricMC 的 [fabric-example-mod](https://github.com/FabricMC/fabric-example-mod)。
